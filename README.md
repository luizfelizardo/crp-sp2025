🧠 Quiz Gabaritando - Concurso CRP-SP


Um quiz interativo desenvolvido para auxiliar psicólogos e estudantes na preparação para o concurso do Conselho Regional de Psicologia de São Paulo (CRP-SP). Teste seus conhecimentos com perguntas baseadas em editais anteriores e nos temas mais relevantes para a prova.

🎯 Objetivo do Projeto
Este projeto foi criado com o objetivo de fornecer uma ferramenta de estudo prática, gratuita e acessível. A ideia é permitir que os candidatos testem seus conhecimentos de forma rápida, identifiquem pontos fracos e reforcem o aprendizado de maneira interativa.

✨ Funcionalidades
Perguntas de Múltipla Escolha: Questões elaboradas no estilo da prova do concurso.

Feedback Imediato: Saiba na hora se você acertou ou errou a questão.

Correção e Dicas: Ao final, veja as respostas corretas e acesse dicas de estudo para as questões que errou.

Pontuação Final: Acompanhe seu desempenho e veja sua pontuação ao terminar o quiz.

Design Responsivo: Acesse e estude confortavelmente no computador, tablet ou celular.

🚀 Como Executar o Projeto
Para rodar este projeto localmente na sua máquina, siga os passos abaixo:

Clone o repositório:

Bash

git clone https://github.com/luizfelizardo/crp-sp2025.git
Acesse o diretório do projeto:

Bash

cd crp-sp2025
Instale as dependências:

Bash

# Se você usa npm
npm install

# Se você usa yarn
yarn install
Inicie o servidor de desenvolvimento:

Bash

# Se você usa npm
npm run dev

# Ou, dependendo do projeto
npm start
Abra seu navegador:
Acesse http://localhost:3000 (ou a porta indicada no seu terminal) para ver o projeto em ação.
