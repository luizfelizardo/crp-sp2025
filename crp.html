Explicação do Tópico

Fundamentos de Computação

A evolução da tecnologia e a migração de ambientes para a nuvem exigiram que os profissionais de TI dominassem a gestão de recursos abstratos. As provas de hoje refletem esse novo paradigma, explorando conceitos como virtualização, computação em nuvem e arquiteturas modernas.

Computação em Nuvem

É crucial entender os modelos de serviço: IaaS (Infraestrutura como Serviço), PaaS (Plataforma como Serviço) e SaaS (Software como Serviço). A prova pode apresentar cenários práticos, por exemplo, a escolha do modelo ideal para um projeto de desenvolvimento de software. A PaaS, que abstrai a infraestrutura e o sistema operacional, é a opção mais adequada para desenvolvedores que precisam focar apenas no código, diferentemente da IaaS, que transfere o gerenciamento do sistema operacional e da infraestrutura para o cliente.

Característica IaaS PaaS SaaS
O que fornece? Máquinas virtuais, armazenamento, redes. Ambiente de desenvolvimento, banco de dados. Aplicativos completos e prontos para uso.
Responsabilidade do Cliente Gerenciar SO, aplicações, dados. Gerenciar apenas a aplicação e os dados. Apenas usar o aplicativo.
Exemplo de Serviço Amazon EC2, Azure VMs. Heroku, Google App Engine. Microsoft 365, Google Workspace.

Sistemas Operacionais

Um profissional de TI para órgãos públicos deve ter domínio de diferentes sistemas operacionais, pois a infraestrutura corporativa é frequentemente um ambiente híbrido.

Active Directory (AD)

O AD, um serviço de diretório da Microsoft, é fundamental para centralizar a gestão de usuários, grupos, computadores e permissões em uma rede Windows. A forma mais comum de aplicar configurações e políticas de segurança em larga escala é por meio de Objetos de Política de Grupo, as GPOs.

Componente Função Primária Importância
Controlador de Domínio (DC) Servidor que hospeda a base de dados do AD. Essencial para autenticação e autorização.
Política de Grupo (GPO) Conjunto de configurações de controle. Automatiza a aplicação de políticas de segurança.

Redes de Computadores

O conhecimento dos modelos de referência OSI e TCP/IP é fundamental. A distinção mais comum em provas é que os **switches** operam na camada de enlace (camada 2 do OSI), interligando dispositivos em uma rede local com base em endereços MAC, enquanto os **roteadores** operam na camada de rede (camada 3), conectando redes diferentes com base em endereços IP.

Segurança da Informação

O candidato deve ser capaz de identificar e distinguir os diferentes tipos de ataques. O **ransomware**, por exemplo, é um tipo de ataque que criptografa os dados da vítima e exige um pagamento para restaurar o acesso. O **phishing**, um ataque de engenharia social, busca enganar o usuário por meio de e-mails ou sites falsos para roubar informações confidenciais, como senhas e dados bancários.

Banco de Dados

A normalização de dados é um conceito central para o modelo relacional, pois visa reduzir a redundância e melhorar a integridade dos dados. As provas exigem a compreensão das Formas Normais (1FN, 2FN, 3FN).

Forma Normal O que Corrige Regra
1ª FN Grupos repetitivos e valores não atômicos. Cada coluna deve conter valores únicos e indivisíveis.
2ª FN Dependências parciais. Todos os atributos não-chave devem depender inteiramente da chave primária.
3ª FN Dependências transitivas. Nenhum atributo não-chave deve depender de outro atributo não-chave.

Desenvolvimento Web e Acessibilidade

A acessibilidade web é um tópico de grande relevância, especialmente para websites de governo. As questões podem abordar a importância de práticas como a adição de descrições textuais em imagens. A marcação `alt` (texto alternativo) é um atributo fundamental do HTML que permite que leitores de tela descrevam o conteúdo de uma imagem para usuários com deficiência visual.

Governança de TI

As questões frequentemente comparam os frameworks, testando o entendimento de que o **ITIL** é sobre a gestão de serviços, enquanto o **COBIT** é sobre a governança e o controle estratégico da TI.

Infraestrutura e Serviços

A alta disponibilidade é um pilar da infraestrutura moderna. O **balanceamento de carga** é a técnica que distribui as requisições de forma inteligente entre múltiplos servidores. Por outro lado, o **failover** é a característica que permite a alternância automática para um sistema de backup em caso de falha do principal.

Gestão de Projetos em TI

O **Scrum** é um framework que se baseia em iterações curtas (sprints), com papéis e cerimônias bem definidos (como o daily Scrum). O objetivo da reunião diária é que a equipe sincronize suas atividades e planeje o trabalho das próximas 24 horas.

Integração de Sistemas

Uma das comparações mais comuns em provas é entre REST e SOAP. O **SOAP** é um protocolo com uma estrutura rígida que usa o formato de mensagem XML. Por outro lado, o **REST** é um estilo arquitetural que se baseia em métodos HTTP e usa formatos de dados leves, como JSON, sendo mais flexível, rápido e escalável.

Suporte e Manutenção de Sistemas

O troubleshooting é a metodologia de análise e resolução de problemas técnicos. As provas podem apresentar cenários para que o candidato identifique a primeira etapa de uma metodologia de resolução de problemas, que é a **"identificação do problema"** com base nos sintomas e relatos do usuário.
